# Hero Blender sources

Place authored `.blend` files here (`core.blend`, `nodes.blend`) when moving off procedural placeholders.

Export glTF Binary → `public/models/hero/`, then:

```bash
npm run hero:compress
```

See [`src/components/three/assets/README.md`](../../src/components/three/assets/README.md) for naming, budgets, and art direction.
